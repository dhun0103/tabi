# tabi

여행(旅, たび) 일정 + 지도 + 가계부를 한 곳에서 쓰는 웹앱(PWA).
홈 화면에 추가하면 앱처럼 쓰고, 링크로 일행과 같이 쓴다.

```text
┌──────────┐     ┌──────────────┐     ┌──────────────┐
│ 내 폰    │ ←→  │  Firestore   │ ←→  │  일행 폰     │
│ (PWA)    │     │  (Firebase)  │     │  (PWA)       │
└──────────┘     └──────────────┘     └──────────────┘
     │ 장소 검색·지도               │ 동선 ↗ 링크
     ↓                              ↓
  Google Maps API (키 있을 때)    구글맵 앱
```

## 기능

```text
tabi
├─ 일정    탭: Day 1…n / 미정(가고 싶은 곳), 하루씩 보기 (여행 중이면 오늘, 아니면 Day 1부터)
│          위: 지도 (그날 번호 핀 + 회색 점선 동선) / 아래: 번호 타임라인 (NOL처럼 번호는 장소 이름 줄, 시간은 그 아래 줄 높이)
│          장소 종류는 NOL·트리플처럼 4가지로 묶어서 표시: 음식점 · 쇼핑 · 숙소 · 관광명소
│                  (구글 세부 종류 "스시/초밥집", "화장품 판매점"은 저장만 해 두고 지출 카테고리 추측에 씀)
│          번호·핀 색도 종류로: 음식점 코랄 · 숙소 민트 · 쇼핑·관광명소 보라
│          지역도 NOL처럼 여행 지역 이름으로: 사카에 & 오스 · 나고야역 · 나고야 성 & 도쿠가와 정원 · 아쓰타 ·
│                  다카야마 · 시라카와고 · 영종도 (좌표 범위로 판단, 범위 밖은 "교토시"처럼 시 이름만)
│          장소·메모 추가는 보고 있는 날에 들어감
│          시간: 24시간 시·분 바퀴로 고르기 (오전/오후 없음, 그날 마지막 일정 1시간 뒤를 먼저 보여 줌)
│          장소 사이 거리·도보 시간
│          일정 사이 메모: 장소와 같은 흰 카드에 글만 ("메모" 글자 없이) + 선 위 파란 점 (NOL처럼)
│          항공편: 파란 원 안 비행기 + 출발 시간, 카드엔 "ICN 09:10 - NGO 10:55 / 제주항공 · 7C1201" (NOL처럼)
│                  번호·지도 핀 없음, 앞뒤 장소 사이 거리는 그대로. 시간순 정리는 출발 시간으로,
│                  거리순 동선 정리에선 바로 앞 장소에 붙어서 같이 움직임
│          맨 아래 [메모 추가] [항공편 추가] [장소 추가] 같은 너비 버튼 (NOL처럼)
│          장소 메모: 카드 안 종류·동네 아래에 "≡ 메모" (아이콘으로 메모인 걸 표시)
│          편집: 화살표로 순서 바꾸기, 거리순 동선 정리, 시간순 정리
│          장소를 누르면 작은 카드 (NOL처럼): 시간·메모를 그 자리에서 바꾸기, 사진 추가,
│                     이 장소에서 쓴 돈 + [지출 추가], 일정 수정·삭제 (상세 보기 없음)
│          일정 수정: 이름·시간·메모만 (장소·날짜는 못 바꿈 → 바꾸려면 삭제하고 새로 추가)
├─ 가계부  엔화/원화 입력 → 적을 때의 환율로 원화 환산(지출마다 저장), 기간별 합계 · 1인당 금액
│          기간 고르기: 기간 전체 · 여행 준비 · Day 1… (직접 그린 드롭다운, 고른 항목은 파랑 + 체크)
│          오른쪽 위 원그래프 버튼 → 카테고리별 지출 페이지 (트리플 "지출내역" 구성 + 원그래프)
│          지출 창: 금액·환율·카테고리·내용·결제 (날짜·장소는 연 곳에서 정해짐)
│          1인당 금액 = 고른 기간의 합계 ÷ 일행 수 (일행이 2명 이상일 때)
└─ 설정    여행 정보·기본 환율·일행, 공유 링크, JSON 백업/복원
새 여행 만들기: 이름 · 날짜 · 일행(이름 칩 + [추가], "나"는 미리 들어가 있음)만
      기본 환율은 묻지 않음 → 화면을 여는 동안 받아 둔 최신 환율로 저장 (못 받으면 900, 설정에서 고침)
헤더: 왼쪽 여행 이름 + 날짜 / 오른쪽 D-day (여행 중엔 "여행 N일째", 끝나면 회색 "다녀온 여행")
      인터넷이 끊기면 D-day 왼쪽에 "● 오프라인" (평소엔 저장 상태 표시 없음)
```

### 지도·장소 검색: 구글 키 유무에 따라 자동 선택

| | 구글 키 있음 (`VITE_GOOGLE_MAPS_API_KEY`) | 키 없음 / 키 오류 |
|---|---|---|
| 지도 | 구글 지도, 한국어 지명 | 일본 국토지리원 연한 지도 (일본만) |
| 장소 검색 | 입력하는 동안 자동완성, 한국어 OK ("나고야성") | OpenStreetMap, 검색 버튼, 일본어·영어가 잘 됨 |
| 장소 카드 | 종류·여행 지역 (평점·영업시간 같은 상세 정보는 안 불러옴) | 같음 |

- 장소 검색 범위는 **일본 + 한국** (출발 전 인천공항·김포공항 등도 넣을 수 있게). 이미 넣은 장소 근처 결과가 먼저 나옴
- 키가 틀렸거나 API가 꺼져 있으면 구글이 알려줘서(`gm_authFailure`) 무료 지도로 자동 전환
- 거리·도보 시간은 직선거리 × 1.3 ÷ 분속 80m 로 계산한 **대략값**
- 거리순 동선 정리: 첫 장소는 고정, 나머지를 가까운 순서(최근접 + 2-opt)로. 메모는 바로 앞 장소에 붙어서 같이 이동

### 환율: 지출을 적을 때의 환율을 그 지출에 저장

```text
지출 추가 (엔화)
   ↓
최신 환율 불러오기 (1시간 안에 받아 둔 값이면 그대로)
   ↓
금액 아래 "≈ 1,023원", 그 밑에 환율 칸이 늘 보임 (엔화일 때만)
  [845.2        ] [오늘 환율]
  11/23(월) 기준 시장 환율이에요. 카드·환전 환율로 고쳐도 돼요.  ← 직접 고치면 "직접 넣은 환율"
   ↓
저장: 금액과 함께 그 환율도 저장
   → 나중에 환율이 바뀌어도 이 지출의 원화 금액·1인당 금액은 그대로
```

| 출처 | 갱신 | 쓰임 |
|---|---|---|
| [ExchangeRate-API](https://www.exchangerate-api.com) 공개 주소 | 주말 포함 매일, 한국 시간 오전 9시쯤 | 1순위 |
| [Frankfurter](https://frankfurter.dev) (유럽중앙은행) | 유럽 평일만, 한국 시간 자정쯤 | 1순위가 안 될 때 |
| 설정의 기본 환율 | 직접 | 인터넷이 안 되고 받아 둔 값도 없을 때, 환율이 저장 안 된 예전 지출 |

- 둘 다 키 없는 무료 API, 시장 중간값(환전·카드 수수료 제외)
- 유럽중앙은행 값만 쓰면 주말·월요일 오전엔 금요일 값이 나와서 1순위를 바꿈
- ExchangeRate-API는 출처 링크를 다는 조건으로 무료 (설정 화면 맨 아래, 환율 수정 칸)

### 카테고리별 지출: 트리플 "지출내역" 구성 + 원그래프

```text
가계부 오른쪽 위 원그래프 버튼 → 흰 화면 전체 페이지 (닫기: ✕ · 휴대폰 뒤로 가기 · Esc)

나고야 여행                        ← 날짜 없이 여행 이름만 (기간은 아래 고르기 칸에)
지출내역입니다.
- - - - - - - - - - - - - - - - -
총 지출 금액             [기간 전체 ▾]   ← 가계부와 같은 값
873,500원                          ← 숫자는 파랑
- - - - - - - - - - - - - - - - -
숙소에서              ╭──────╮
가장 많이 썼어요.     │ 숙소  │      ← 얇은 원그래프
                      │47.2% │
                      ╰──────╯
- - - - - - - - - - - - - - - - -
🛏 숙소              47.2%  ▬▬▬    ← 오른쪽 짧은 막대 (가장 큰 게 40px)
   412,000원
🍴 식비              21.3%  ▬
   …
```

- 줄이나 원그래프 칸을 누르면: 문장이 "숙소에 412,000원 썼어요."로, 가운데 비율도 그 카테고리로, 나머지는 흐리게. 다시 누르면 처음으로
- 큰 제목이 위로 지나가면 위 막대에 여행 이름이 작게 나옴 (트리플처럼)

| 카테고리 | 색 |
|---|---|
| 숙소 | 남보라 `#5B3FD6` |
| 식비 | 호박색 `#F59E0B` |
| 쇼핑 | 산호빨강 `#F04452` |
| 교통 | 파랑 `#2F87F2` (앱 버튼 색) |
| 관광 | 민트 `#0E9A90` (가계부 아이콘 색) |
| 기타 | 회색 `#B0B8C1` |

- 색은 순위가 아니라 카테고리를 따라감 → 기간을 바꿔도 같은 카테고리는 같은 색
- 원그래프는 큰 순서라 어느 두 칸이든 붙을 수 있어서, 6색 모든 쌍을 색약 시뮬레이션까지 계산해 고름 (흰 바탕 ΔE 11.3 이상, 일반 시야 16.6 이상)
- 1% 미만인 칸도 틈에 묻히지 않게 가는 조각으로 보여 줌. 정확한 금액·비율은 아래 목록에 항상 글자로

### 사진: 사진 전용 저장소 없이 무료 요금제 안에서

```text
[사진 추가] → 폰 사진첩/카메라
   ↓
폰에서 긴 변 1280px JPEG로 줄이기 (장당 약 150~400KB)
   ↓
Firestore 문서 하나에 그대로 저장 (trips/{여행}/photos, 문서 한도 1MB 안쪽)
   ↓
일행 폰에서도 그 장소 카드를 열면 보임 (장소별로만 받아 와서 데이터 절약)
```

- Firebase 사진 전용 저장소(Storage)는 종량제(카드 연결) 요금제가 필요해서 안 씀
- Firestore 무료 저장 1GB → 이 크기면 사진 수천 장. 원본 화질은 아니고 폰 화면용
- 장소를 지우면 그 장소 사진도 같이 지움. JSON 백업에는 사진이 안 들어감
- 이 기기 저장 모드(Firebase 없음)에선 사진을 IndexedDB에 저장

### 저장·공유

- `.env.local`에 Firebase 설정이 있으면 **실시간 공유**, 없으면 **이 기기에만 저장**
- 오프라인: 앱 화면은 서비스워커가, 데이터는 Firestore 캐시가 들고 있어서 끊겨도 보고 입력 가능 → 연결되면 자동 동기화 (끊긴 동안 헤더에 "● 오프라인")
- 공유 방식: 로그인 없음. 공유 링크 안의 20자 랜덤 ID를 아는 사람만 접근 (`firestore.rules`)

## 로컬 실행

```bash
npm install
npm run dev          # http://localhost:5173
npm run build        # 타입 검사 + 빌드 (dist/)
npm run icons        # public/logo.svg 로 아이콘 다시 만들기
```

폰에서 바로 보려면 `npm run dev -- --host` 후 같은 와이파이에서 `http://<PC IP>:5173` (http라 오프라인 기능은 배포 후에만 동작)

## Firebase 연결 (일행 공유용)

1. https://console.firebase.google.com → 프로젝트 만들기 (Google 애널리틱스는 꺼도 됨)
2. 빌드 → Firestore Database → 데이터베이스 만들기 → 위치 `asia-northeast1 (Tokyo)` → 프로덕션 모드
3. Firestore → 규칙 탭 → `firestore.rules` 내용 붙여넣기 → 게시
4. 프로젝트 개요 → 웹 앱 추가(`</>`) → 나오는 `firebaseConfig` 값을 `.env.example` 참고해서 `.env.local`에 입력

## 구글 지도·장소 API 연결

```text
Google Cloud 콘솔 (Firebase와 같은 프로젝트 사용 가능)
→ 결제 계정 연결 (카드 등록 필요, 아래 무료 한도 안이면 0원)
→ API 사용 설정: Maps JavaScript API, Places API (New)
→ 사용자 인증 정보 → API 키 만들기
   · 애플리케이션 제한: 웹사이트 → http://localhost:5173/*, https://<배포주소>/*
   · API 제한: Maps JavaScript API, Places API (New) 두 개만
→ (권장) 지도 관리 → 지도 ID 만들기 (JavaScript) → VITE_GOOGLE_MAP_ID
→ (권장) 결제 → 예산 및 알림 → 월 예산 알림 (넘으면 메일)
→ .env.local 에 VITE_GOOGLE_MAPS_API_KEY 입력
```

요금이 새지 않게 막는 장치

```text
무료 체험판 결제 계정   직접 "유료 계정으로 업그레이드"를 누르기 전엔 청구 없음
키 제한               허용한 웹사이트 + API 2개에서만 동작
예산 알림             월 예산을 넘으면 메일
하루 요청 상한         ✕ 콘솔에서 지도·장소 API 할당량이 "조정 불가"로 나옴
지출 한도(자동 정지)    ✕ Cloud Run·Gemini 등 일부 서비스만 대상, 지도 API는 안 됨
```

요금: SKU마다 매달 무료 한도 (Essentials 10,000건 · Pro 5,000건 · Enterprise 1,000건).
지도 로드·자동완성은 Essentials, 검색 결과 고르기(위치·이름·종류)는 Pro라 개인 여행용이면 보통 한도 안.
평점·영업시간·전화(Enterprise)와 장소 사진은 장소 카드에 안 넣어서 요청하지 않는다.

## 폰에 설치

- 아이폰: 사파리로 열기 → 공유 버튼 → 홈 화면에 추가 → **홈 화면 아이콘으로 열어서 시작** (사파리와 저장공간이 따로)
- 안드로이드: 크롬으로 열기 → ⋮ → 홈 화면에 추가 (또는 앱 설치)
- 일행: 설정 → 링크 공유하기 → 받은 링크로 열기 (홈 화면 앱에서 처음 열 땐 "공유 링크로 참여"에 붙여넣기)
- 업데이트: 새 버전을 배포하면 탭바 바로 위(엄지 닿는 곳)에 "새 버전이 나왔어요 [새로고침]" → 누르면 바로 바뀜
  (안 누르면 앱을 완전히 껐다 켤 때 바뀜. 입력 중에 갑자기 새로고침되지 않게 일부러 이렇게 함)
